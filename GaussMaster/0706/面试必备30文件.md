## 面试准备重点

### 重点 1: RAG 流程

```
用户问题
    ↓
ask_gauss() → search() → 向量检索 + 文本检索
    ↓
reranker() → 重排
    ↓
llm_generation() → 生成答案
```

**核心文件：**

- `data_transformer.py` → `ask_gauss()`
- `retriever_util.py` → 检索
- `gaussdb_vector.py` → 向量搜索

***

### 重点 2: Funcall 机制

```
用户问题
    ↓
infer_tool_name() → 推断工具
    ↓
infer_arguments() → 推断参数
    ↓
verify_arguments() → 验证参数
    ↓
call_tool() → 执行工具
```

**核心文件：**

- `executor.py` → 全部逻辑

***

### 重点 3: 向量搜索

```
用户问题
    ↓
query_embedding() → 向量化
    ↓
ORDER BY text_vector <-> [向量] → 按距离排序
    ↓
LIMIT topk → 返回最相似结果
```

**核心文件：**

- `gaussdb_vector.py` → search\_vector()

***

### 重点 4: Agent 交互

```
用户问题
    ↓
DBA.interaction() → 主入口
    ↓
interact_with_tool() → 工具调用
    ↓
infer_tool_name() → 匹配工具
    ↓
call_tool() → 执行并返回
```

**核心文件：**

- `dba.py` → Agent 主类

***

### 重点 5: 会话管理

```
用户请求 → user_id + session_id
    ↓
检查 SESSION_QA_HISTORY → 本地缓存
    ↓
如果没有 → 查数据库 → InteractionMemory
    ↓
保存到本地 + 持久化到数据库
```

**核心文件：**

- `global_vars.py` → 会话存储
- `context_manager.py` → 上下文切换
- `dao_interaction_memory.py` → 数据库持久化

***
