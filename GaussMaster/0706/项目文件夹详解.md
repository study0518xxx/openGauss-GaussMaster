# GaussMaster 项目文件夹详解

## 项目根目录

```
GaussMaster/
├── __init__.py           # 包初始化（空文件）
├── constants.py          # 全局常量定义
├── global_vars.py        # 运行时全局变量
── startup.py            # 启动脚本入口
├── controllers/          # API 路由层
├── server/               # 业务逻辑层
├── multiagents/          # Agent 层
├── llms/                 # LLM 对接层
├── utils/                # 工具函数层
├── common/               # 公共组件层
├── config/               # 配置文件目录
└── 0705/                 # 学习笔记
```

---

## 1. 根目录核心文件

| 文件 | 作用 | 类比 |
|------|------|------|
| **`__init__.py`** | 标记 GaussMaster 为 Python 包 | "我是包"标签 |
| **`constants.py`** | 定义全项目共享的常量（路径、配置名、版本号） | 字典 |
| **`global_vars.py`** | 运行时共享的变量（会话历史、工具注册、语言配置） | 内存仓库 |
| **`startup.py`** | 项目启动入口（setup/start/stop 命令） | 开关 |

---

## 2. controllers/ - API 路由层

| 文件 | 作用 |
|------|------|
| **`core.py`** | 核心 API 路由：ask_gauss、intelligent_interaction、clusters 等 |

**类比：** 前台接待员，接收用户请求并分发给处理部门

---

## 3. server/ - 业务逻辑层

| 文件 | 作用 |
|------|------|
| **`web/data_transformer.py`** | **核心业务逻辑**：RAG 流程、LLM 调用、知识库管理 |
| **`web/context_manager.py`** | 会话上下文管理、LLM 切换 |
| **`web/jsonify_utils.py`** | 数据库查询结果转 JSON |
| **`multicluster.py`** | 多集群管理、实例切换 |

**类比：** 大脑中枢，所有智能处理的核心

---

## 4. multiagents/ - Agent 层

| 文件/文件夹 | 作用 |
|-------------|------|
| **`agents/dba.py`** | **唯一真正的 Agent**：理解问题、调用工具、返回答案 |
| **`agents/base_agent.py`** | Agent 基类 |
| **`agents/prompt/dba_prompt.py`** | DBA Agent 的 Prompt 模板 |
| **`config/agent_config.py`** | Agent 角色定义（SQLExpert、StorageExpert 等标签） |
| **`config/dbmind_config.py`** | DBMind 工具配置 |
| **`tools/dbmind_interface.py`** | DBMind API 接口封装 |

**类比：** 专业员工，但目前只有一个 DBA 员工

---

## 5. llms/ - LLM 对接层

| 文件 | 作用 |
|------|------|
| **`executor.py`** | **Funcall 机制**：工具推断、参数验证、调用执行 |
| **`llm_utils.py`** | LLM 消息格式、角色定义 |
| **`pangu_cloud.py`** | 盘古模型对接、function_call 解析 |
| **`prompt.py`** | 各种 Prompt 模板定义 |

**类比：** 翻译官，负责和外部大模型沟通

---

## 6. utils/ - 工具函数层

| 文件 | 作用 |
|------|------|
| **`retriever_util.py`** | **检索工具**：Embedding 调用、重排、多路召回融合 |
| **`prompt_util.py`** | Prompt 构建：HyDE、Query Transform 等 |
| **`parse.py`** | LLM 输出解析、工具调用提取 |
| **`split_util_md.py`** | Markdown 文档分块 |
| **`split_util_docx.py`** | Word 文档分块 |
| **`doc_util.py`** | 文档处理入口 |
| **`ui_output_util.py`** | 前端输出格式化（表格、图表、按钮） |
| **`case_to_db.py`** | 知识库导入 |

**类比：** 各种小工具，辅助核心业务

---

## 7. common/ - 公共组件层

| 文件夹/文件 | 作用 |
|-------------|------|
| **`metadatabase/dao/gaussdb_vector.py`** | **向量数据库操作**：增删改查、向量搜索 |
| **`metadatabase/dao/dao_interaction_memory.py`** | 会话持久化 |
| **`metadatabase/ddl.py`** | 数据库表创建 |
| **`safety/word_detect.py`** | **DFA 敏感词检测** |
| **`security.py`** | **AES256 加密**、密码强度检查 |
| **`http/ssl.py`** | SSL/TLS 配置 |
| **`configs/config_utils.py`** | 配置加载、加密 |
| **`utils/checking.py`** | 参数校验 |

**类比：** 基础设施，提供安全、数据库、配置等基础服务

---
