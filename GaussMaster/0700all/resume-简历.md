#### 核心项目：GaussMaster — LLM 驱动的数据库智能运维 Copilot
**2024 年 6 月 - 2025 年 6 月 | 核心开发者**

项目概述：基于大语言模型的 openGauss 数据库智能运维系统，覆盖问答、故障诊断、巡检、调优全生命周期。项目已在中国农业银行生产环境部署，34 个运维场景实现零人工干预，QA 回答高质量率 85.23%，相关论文发表于 arXiv（2506.23322）。

个人职责与成果：

- **设计并实现了 RAG 混合检索管道**（向量检索 + BM25 全文检索 + 微调重排序），评估 LangChain 后决定核心链路自研，深度集成 openGauss GSDiskANN 磁盘向量索引，摆脱框架限制，提升检索精度与系统可控性。同时设计了 HyDE + 查询改写的两级降级策略，将空结果概率降低约 40%。

- **设计了模型无关的两阶段工具调用方案**，放弃依赖各 LLM 的原生 Function Call API，统一通过提示工程实现"先选工具名、再填参数"的两步分离。该方案统一适配盘古 / DeepSeek / ChatGLM / 百川 / Qwen 等 6 种模型，工具选择准确率从 60% 提升至 95%+，参数填充准确率 99%+。

- **基于数据库内核经验，定义了 21 个运维诊断工具的接口与参数 Schema**，设计并实现了 inspect.signature 确定性参数校验机制，确保 LLM 输出的参数在调用前经过严格的类型和完整性验证，杜绝生产环境误操作。

- **设计了层次化多 Agent 协同诊断架构**，通过诊断树引导的确定性工具路径替代 LangChain/LangGraph 的自由探索模式，在 34 个根因场景中稳定性与准确率显著优于通用 Agent 方案。

**技术栈**：Python、FastAPI、openGauss、GSDiskANN、BM25、BGE-large、盘古 / DeepSeek、asyncio、psycopg2
