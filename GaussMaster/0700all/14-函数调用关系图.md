## 一、RAG 问答全链路（最核心）

```
用户: "CPU 为什么飙到 90%"
│
controller/core.py
├─ @request_mapping("/v1/api/ask_gauss")   ← 路由入口
│
└─ ask_gauss()                             ← data_transformer.py:448
   │
   ├─ DFA_DETECTOR.is_unsafe_text(question) ← 安全检测：Trie树 O(n) <1ms
   │  └─ 命中 → 直接拒绝
   │
   ├─ search()                             ← data_transformer.py:183
   │  │
   │  ├─ BaseRetriever.search_vector_result_gaussdb()  ← retriever_util.py:115
   │  │  └─ OnlineEmbedding.query_embedding(query)      ← HTTP POST
   │  │     └─ GaussDB.search_vector()                  ← gaussdb_vector.py:177
   │  │        └─ SELECT ... ORDER BY text_vector <-> '[...]' LIMIT 10
   │  │           └─ GSDiskANN 索引加速
   │  │
   │  ├─ BaseRetriever.search_text_result_gaussdb()    ← retriever_util.py:120
   │  │  └─ GaussDB.search_text()                       ← gaussdb_vector.py:200
   │  │     └─ SELECT ... ORDER BY text ### 'CPU...' DESC LIMIT 10
   │  │        └─ BM25 索引加速
   │  │
   │  └─ BaseRetriever.reranker_search_result()         ← retriever_util.py:154
   │     └─ OnlineReranker.compute_score(pairs)         ← HTTP POST
   │        └─ 过滤 score < 0
   │           └─ return sorted_results[:topk]
   │
   ├─ 有结果?
   │  ├─ YES → llm_generation()            ← data_transformer.py:569
   │  │        └─ generate_answer()         ← data_transformer.py:416
   │  │           └─ thread_request_from_llm()           ← stream=True
   │  │              └─ SSE 流式 yield
   │  │
   │  └─ NO  → query_opt_process()          ← data_transformer.py:597

   │

      └─ gaussdb_vector.insert_qa_record(qa_dict)  ← 落库 qa_record 表
```

```
═══════════════════════════════════════════════════════════

  │

───────────────────────────────────────────────────────────

  │

  │
```

## 八、检索降级决策树

```
search(question, vector_topk=5, text_topk=5, rerank_topk=3)
│
├─ search_vector_result_gaussdb() ──┬── 并行执行
├─ search_text_result_gaussdb()  ──┘
│
├─ 合并去重
│
├─ reranker_search_result()
│  ├─ compute_score(pairs) → BGE-reranker
│  └─ 过滤 score < 0
│     └─ return sorted_results[:topk]
│
├─ len(results) > 0?
│  │
│  ├─ YES → llm_generation()
│  │        └─ generate_answer() → SSE 流式
│  │
│  └─ NO → 降级策略
│          │
│          ├─ 降级一: HyDE
│          │  └─ LLM.generate("假设的完美答案")
│          │     └─ OnlineEmbedding(假答案) → 重新向量检索
│          │        ├─ 有结果? → llm_generation()
│          │        └─ 无结果? → 继续降级
│          │
│          └─ 降级二: 查询改写
│             └─ LLM.generate("拆成3个子问题")
│                └─ for each 子问题:
│                   └─ search() → 合并结果
│                      ├─ 有结果? → llm_generation()
│                      └─ 无结果? → "知识库中没有相关知识"
```
