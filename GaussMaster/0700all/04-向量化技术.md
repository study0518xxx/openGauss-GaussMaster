## 向量数据库：openGauss（不是 Milvus）

### 为什么选 openGauss 自身？

| 方案 | 问题 |
|------|------|
| Milvus | 需要额外部署，跨系统数据同步复杂，不支持 BM25 全文索引 |
| Chroma/FAISS | 轻量但不适合生产级百万级文档块 |
| **openGauss** | PostgreSQL 兼容，一张表同时支持 floatvector + BM25，GSDiskANN 磁盘索引 |

## 索引类型：GSDiskANN

### 为什么选 GSDiskANN 而不是 IVF_FLAT / HNSW？

- 银行场景知识库数据量大（百万级文档块）→ 内存放不下全部向量 → 必须用磁盘索引
- GSDiskANN 是 openGauss 自研的磁盘向量索引算法，基于 Microsoft DiskANN
- 支持 Product Quantization（PQ）压缩，大幅降低内存占用
- 和 BM25 可同表共存，混合检索无需跨系统

### 索引创建 SQL
```python
def _create_index_vector(self):
    self.cur.execute('set maintenance_work_mem=1024000')
    for embedding_key in self.embedding_keys:
        index_sql = f'''
            CREATE INDEX ON "{table}" 
            USING gsdiskann("{embedding_key}_vector" l2) 
            WITH (
                pq_nseg={1024},    -- PQ 段数（=维度数）
                pq_nclus={16},     -- 聚类数
                queue_size={100},  -- 搜索队列
                num_parallels={30}, -- 并行度
                enable_pq=true     -- 开启乘积量化
            )
        '''
        self.cur.execute(index_sql)
```

### 索引参数详解

| 参数 | 值 | 说明 |
|------|-----|------|
| `using` | gsdiskann | openGauss 自研算法，微软 DiskANN 的变体 |
| `distance_strategy` | l2 | 欧几里得距离 |
| `pq_nseg` | 1024 | 乘积量化段数，等于嵌入维度 |
| `pq_nclus` | 16 | 聚类中心数（默认 NCLUS 值），平衡精度与速度 |
| `queue_size` | 100 | 搜索时优先队列大小，越大精度越高但越慢 |
| `num_parallels` | 30 | 索引构建和查询并行度 |
| `enable_pq` | true | 开启乘积量化压缩，减少约 10x 内存 |

## BM25 文本索引

```python
def _create_index_bm25(self):
    for table in self.tables:
        bm25_index_sql = f'''
            CREATE INDEX ON "{table}" 
            USING bm25({bm25_fields}) 
            WITH (num_parallels={30})
        '''
        self.cur.execute(bm25_index_sql)
```

BM25 用于关键词级别的文本检索，作为向量检索的兜底——当语义相似度匹配不到好结果时，用关键词命中补充。

## 重排序

### 配置
```yaml
reranker_model:
  enable: True
  model_name: bge-reranker-finetune
  api_url: http://*.*.*.*:*/get_reranker_result
```

### 实现
```python
class OnlineReranker():
    async def compute_score(self, pairs):
        data = {"pairs": pairs}  # [[query, doc1], [query, doc2], ...]
        response = await session.post(url=self.url, data=json.dumps(data))
        return response.json()  # 分数列表
```

### 关键决策：score < 0 过滤
重排序后的分数低于 0 的文档直接丢弃，确保进入 LLM 上下文的都是正向相关的知识片段，减少幻觉。

## 全链路总结

```
用户提问
  → OnlineEmbedding.query_embedding() → 1024 维向量
  → GaussDB.search_vector() → <-> L2 距离 + GSDiskANN 索引 → Top-K
  → GaussDB.search_text() → ### BM25 排名 → Top-K
  → AdjacentRetriever → 前后块拼接
  → OnlineReranker.compute_score() → 过滤 score<0
  → 最终上下文进入 LLM prompt
```
