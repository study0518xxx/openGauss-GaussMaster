# 01 - 系统架构

## 1. Server 架构

### 1.1 框架选型
**FastAPI + Uvicorn**，通过自建 `HttpService` 抽象层封装，方便切换框架。

```python
# GaussMaster/common/http/_service_impl.py
class HttpService:
    def __init__(self, name=__name__):
        self.app = FastAPI(title=name, openapi_url=None, docs_url=None, redoc_url=None)
```

设计文档注释明确写明了从 Flask → FastAPI 的迁移背景，解耦层保证"换框架不改业务代码"。

### 1.2 核心 API 端点

| 端点 | 方法 | 功能 | 输出格式 |
|------|------|------|---------|
| `/v1/api/ask_gauss` | POST | RAG 问答 | SSE 流式 |
| `/v1/api/search` | POST | 纯检索（向量 + BM25 + 重排序） | JSON |
| `/v1/api/infer` | POST | 纯 LLM 推理（已知上下文） | SSE 流式 |
| `/v1/api/app/intelligent-interaction` | POST | 工具交互 / 故障诊断 | SSE 流式 |
| `/v1/api/clusters` | GET/PUT | 集群管理 | JSON |
| `/v1/api/clusters/register` | POST | 注册 openGauss 实例 | JSON |
| `/v1/api/llms` | GET/PUT | LLM 列表 / 切换 | JSON |
| `/v1/api/serve/knowledge_base/*` | 多种 | 知识库 CRUD | JSON |
| `/v1/api/feedback/*` | 多种 | 用户反馈（赞/踩/举报） | JSON |

### 1.3 中间件
- **语言检测**：从 `Accept-Language` 请求头自动切换中英文
- **LLM 上下文切换**：`@switch_llm_context_decorator` 在工具调用前自动设置用户/会话的 LLM 实例

### 1.4 启动流程
```
加载配置 → 初始化日志 → 初始化嵌入模型 → 检测可用 LLM 并设默认
→ 初始化 Agent 组件（注册所有工具） → 初始化集群代理 → 启动 Uvicorn
```

### 1.5 前端通信
前端（Vue.js + Vite + TypeScript，`ui/` 目录）通过 `VITE_BASE_PROXY_URL` 配置代理到后端。所有 LLM 输出使用 SSE（`text/event-stream`），CRUD 操作用标准 JSON。

## 3. 依赖的外部服务

| 服务 | 角色 | 接口 |
|------|------|------|
| DBMind | 纳管 openGauss 实例，提供 25 个诊断工具 | RESTful API |
| 向量数据库 | 存储知识片段嵌入，在线相似性检索 | HTTP |
| 嵌入模型 | 将用户提问向量化 | HTTP API |
| 重排序模型 | 对检索到的知识片段做相关性排序 | HTTP API |
| LLM 推理 | 问答和运维推理 | HTTP API |
