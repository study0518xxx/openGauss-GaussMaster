# GaussMaster 核心数据结构 & 表结构大全

---

## 一、所有数据库表结构

### 1. gauss_kb — 知识块表（核心 RAG 依赖）

```
所在库: vector_dbname (openGauss, psycopg2)
表名: gauss_kb
特点: 有 floatvector(1024) 向量列 + GSDiskANN + BM25 双索引
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `uuid` | TEXT | 块唯一ID (UUID4) |
| `field` | TEXT | 所属领域 (GaussDB) |
| `source` | TEXT | 来源 (idp/community/huawei_cloud) |
| `product_format` | TEXT | 部署形态 (centralized/distributed/miniaturize) |
| `sub_field` | TEXT | 子领域 (kernel) |
| `doc_location` | TEXT | 源文件路径 |
| `title` | TEXT | 标题 (含层级前缀) |
| `text` | TEXT | 文本内容 |
| `text_vector` | **floatvector(1024)** | **1024维向量（唯一有向量索引的列）** |
| `visualize` | TEXT | 可视化链接 |
| `link` | TEXT | 外部链接 |
| `version` | TEXT | 产品版本 (24.7.30.10) |
| `context` | TEXT | 上下文链 [prev_uuid, cur_uuid, next_uuid] |
| `keyword` | TEXT | 关键词 |
| `confidence` | TEXT | 置信度 (1=最高/2=中等/unknown) |
| `ds_id` | TEXT | 数据源ID |
| `prev_uuid` | TEXT | 前一块UUID (链表指针) |
| `next_uuid` | TEXT | 后一块UUID (链表指针) |

**索引**：`gsdiskann(text_vector l2)` + `bm25(text)`

## 二、核心代码数据结构（Python 类）

### 1. Registry — 工具注册表

```python
# common/plugins/registry.py
class Registry(dict):
    _dict = {}                         # {tool_name: tool_function}
    _category = {                      # 按角色分组的工具映射
        'SQLExpert': {tool_name: func},
        'StorageExpert': {tool_name: func},
        'ClusterExpert': {tool_name: func},
        ...
    }

    # 关键属性
    detail_str_list        → (带参描述列表, 不带参描述列表)  # 用于普通LLM prompt
    detail_dict_list       → (带参字典列表, 不带参字典列表)  # 用于盘古云 prompt
    all                    → 全部工具 dict
    get_role_tools(role)   → 指定角色的工具集
```

**用法**：`@base_tools(name="risk_analysis", description="...", params=[Param(...)])` 装饰函数即注册。

### 2. Param — 工具参数定义

# common/plugins/param.py
class Param:
    name: str           # 参数名 (如 "metric")
    description: str    # 参数描述 (如 "指标名称，如cpu_usage")
    type: str           # 参数类型 (如 "str", "int")
    default_value: obj  # 默认值
    required: bool      # 是否必填 (默认 True)

### 3. BaseLLM — LLM 抽象基类

```python
# llms/base/BaseLLM.py
class BaseLLM(ABC):
    name: str           # 模型名
    url: str            # API地址
    temperature: float  # 温度参数
    stream: bool        # 是否流式

    @abstractmethod
    llm_type → str      # 返回 LLMType 枚举值

    @abstractmethod
    async invoke(prompt: list|str) → (content: str, function_call: dict|None)
```

**实现类**：`Pangu`, `PanguCloud`, `Chatglm`, `Baichuan`, `Llama3`
