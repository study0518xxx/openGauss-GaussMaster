# DBMind 详解

## 1. 概述

**DBMind** 是 openGauss 数据库的**自治运维平台**，是 GaussMaster 的重要依赖组件。

**一句话解释：** DBMind = **数据库自动驾驶系统**，让数据库能"自己发现问题、自己解决问题"。

---

## 2. 核心能力

| 功能 | 说明 |
|------|------|
| **索引推荐** | 自动分析慢 SQL，推荐合适的索引 |
| **异常检测** | 监控数据库指标，自动发现异常 |
| **慢 SQL 根因分析** | 分析慢 SQL 产生的原因 |
| **时序预测** | 预测数据库未来状态的走势 |
| **参数调优** | 自动调整数据库参数达到最优性能 |
| **故障自修复** | 检测到故障后自动修复 |
| **多指标关联分析** | 把多个指标关联起来分析问题根因 |

---

## 3. GaussMaster 与 DBMind 的关系

```
┌─────────────────────────────────────┐
│           用户（你）                │
│    "帮我看看数据库有没有问题"        │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│        GaussMaster (前端 AI)        │
│   - 理解用户问题                    │
│   - 调用 DBMind 的工具              │
│   - 组织回答                        │
└────────────────┬────────────────────┘
                 │ 调用工具
                 ▼
┌─────────────────────────────────────┐
│       DBMind (数据库运维后端)       │
│   - 实际执行数据库操作              │
│   - 返回监控数据、诊断结果           │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│         openGauss 数据库            │
│   - 存储数据                        │
│   - 执行 SQL                        │
│   - 上报指标                        │
└─────────────────────────────────────┘
```

---

## 4. 运行模式

DBMind 支持多种运行模式：

| 模式 | 说明 |
|------|------|
| **命令行交互式** | `gs_dbmind` 直接输入命令操作 |
| **服务式** | 启动 RESTful API 服务，被 GaussMaster 调用 |
| **Prometheus 模式** | 对接 Prometheus 监控系统 |

---

## 5. GaussMaster 为什么需要 DBMind？

GaussMaster 本身**不直接连接数据库**，而是通过 DBMind 间接管理：

- GaussMaster = **AI 大脑**（理解问题、组织回答）
- DBMind = **工具箱**（提供诊断、索引推荐等能力）

**示例流程：**

```
用户问："最近有哪些慢 SQL？"
    ↓
GaussMaster 收到问题
    ↓
调用 DBMind 的慢 SQL 查询工具
    ↓
DBMind 返回慢 SQL 列表
    ↓
GaussMaster 组织成自然语言回答用户
```

---

## 6. 总结

| 组件 | 角色 | 类比 |
|------|------|------|
| **DBMind** | 数据库运维后端 | 专业的数据库医生 |
| **GaussMaster** | AI 交互前端 | 医生的翻译/助手 |

没有 DBMind，GaussMaster 就失去了"动手能力"，只能空谈理论。
