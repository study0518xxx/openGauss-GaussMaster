# 敏感词检测机制详解

## 1. 核心原理：DFA 算法

**DFA** = **Deterministic Finite Automaton**，使用**前缀树（Trie 树）**实现敏感词匹配。

---

## 2. 工作流程图

```
用户输入: "我想查询西藏的数据"
           ↓
┌─────────────────────────────────────┐
│  1. 加载敏感词库                     │
│     word_list.txt (1292个敏感词)     │
└────────────────┬────────────────────┘
                 ↓
┌─────────────────────────────────────┐
│  2. 构建前缀树 (Trie)                │
│                                     │
│        敏                            │
│       / \                           │
│      感  感                          │
│       \  /                          │
│       感 ← "敏感" 完整匹配           │
└────────────────┬────────────────────┘
                 ↓
┌─────────────────────────────────────┐
│  3. 逐字符遍历输入                   │
│     "西" → 树中有吗？→ 没有 → 跳过   │
│     "藏" → 树中有吗？→ 没有 → 跳过   │
│     "的" → 树中有吗？→ 没有 → 跳过   │
│     "数" → 树中有吗？→ 没有 → 跳过   │
│     "据" → 树中有吗？→ 没有 → 跳过   │
└────────────────┬────────────────────┘
                 ↓
         没有匹配 → 返回 False (安全)
```

## 3. 核心代码解析

**位置：** `GaussMaster/common/safety/word_detect.py`

### 前缀树结构

```python
# 比如敏感词 ["西藏", "敏感"] → 构建成前缀树
root = {
    '敏': {
        '感': {'is_end': True},  # "敏感" 结束
        '...'
    },
    '西': {
        '藏': {'is_end': True}   # "西藏" 结束
    }
}
```

### 判断逻辑

```python
def is_unsafe_text(self, text):
    """逐字符检查是否有敏感词"""
    for i in range(len(text)):
        total_length, _, _ = self.match_word(text[i:])
        if total_length != 0:  # 匹配到敏感词
            return True  # 不安全
    return False  # 安全
```

## 4. 敏感词库内容

**位置：** `GaussMaster/common/safety/data/word_list.txt`

敏感词包括：

| 类别 | 示例 |
|------|------|
| **政治相关** | 领导人、领土、民主、独裁 |
| **暴力犯罪** | 杀人、毒品、枪支、炸弹 |
| **色情低俗** | 色情、裸聊、做爱 |
| **脏话粗口** | 傻逼、装逼、我操 |
| **社会事件** | 游行、罢工、抗议 |
| **其他** | 身份证、银行卡、作弊 |

**总计：** 1292 个敏感词

## 5. 使用示例

```python
# 判断逻辑
if (safety_check == 'TRUE' and DFA_DETECTOR.is_unsafe_text(question)):
    # 拒绝处理，返回安全警告
    return "您的提问包含敏感内容，请重新提问"
```

| 用户输入 | 结果 |
|----------|------|
| "查询数据库性能" | ✅ 安全 |
| "西藏的集群在哪" | ❌ 包含"西藏" |
| "帮我分析这个问题" | ✅ 安全 |
| "去你妈的" | ❌ 包含脏话 |

## 6. 配置开关

在 `gauss_master.conf` 中配置：

```ini
[SAFETY]
safety_check = TRUE  # 启用敏感词检测
```

---

## 7. 总结

| 组件 | 说明 |
|------|------|
| **DFA 算法** | 前缀树匹配，效率高 O(n) |
| **敏感词库** | 1292 个词，手动维护 |
| **判断逻辑** | 匹配到任意一个敏感词 → 不安全 |
| **配置开关** | `safety_check = TRUE/FALSE` 控制是否启用 |

这是一个**基于规则的传统方法**，而不是 AI 判断。好处是简单快速，坏处是只能识别词库中有的词。
