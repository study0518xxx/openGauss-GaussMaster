## 使用建议

1. **按模块复习**：根据自己的负责范围，重点看对应模块
2. **由浅入深**：先看基础问题，再进阶，最后深挖
3. **手写代码**：每份文件末尾都有手写代码题，建议动手实现
4. **结合实际**：回答时结合自己在项目中的实际工作，更有说服力

## 面试策略

### 开场（30秒）
> GaussMaster 是一个基于 RAG + Multi-Agent 的智能数据库运维问答系统。我主要负责 XXX 模块，深入理解了检索增强生成、流式输出、三层记忆等核心设计。

### 展开（按模块）
- 讲清楚数据流：用户提问 → 检索 → 生成 → 输出
- 突出设计亮点：SSE 流式、三层记忆、工具自动注册、Token 自动刷新
- 体现技术深度：同步转异步、DFA 算法、连接池管理

### 收尾（展示思考）
- 主动谈优化方向：连接池、限流熔断、多模态
- 展示对业务的理解：为什么选择 RAG、为什么用 openGauss
