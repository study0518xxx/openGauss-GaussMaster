### Q2: DFA 敏感词检测是怎么实现的？

**回答要点**：
- **核心思想**：用 Trie 树（前缀树）构建状态转移图，逐字符匹配
- **构建阶段**：加载敏感词文件，每个词是一条路径，终点标记 `is_end=True`
- **匹配阶段**：对文本每个位置开始沿 Trie 走，走到 `is_end=True` 即命中
- **停用词处理**：跳过空格、标点等干扰字符

## 二、进阶问题

### Q4: 为什么用 DFA 而不是正则表达式？

**回答要点**：
| 对比 | DFA | 正则表达式 |
|:---|:---|:---|
| 匹配速度 | O(N) 每个字符一次查表 | 回溯可能指数级 |
| 多模式匹配 | 一次遍历匹配所有敏感词 | 需要多个正则或复杂模式 |
| 内存占用 | 共享前缀，节省空间 | 编译后的状态机可能很大 |
| 停用词支持 | 天然支持跳过 | 需要额外处理 |

**结论**：敏感词数量多、需要高性能时，DFA 更优。

2. **上下文判断**：结合 NLP 模型判断是否为恶意（当前未实现）

## 三、深挖问题

### Q7: DFA 的时空复杂度是多少？有什么优化空间？

**回答要点**：
- **时间复杂度**：
  - 构建：O(所有敏感词总长度)
  - 匹配：O(N × M)，N 是文本长度，M 是最长敏感词长度
  - 实际中 M 很小，近似 O(N)
- **空间复杂度**：O(所有敏感词总长度 × 字符集大小)
- **优化方向**：
  1. AC 自动机：多模式匹配，一次遍历匹配所有敏感词
  2. 双数组 Trie：压缩空间
  3. 布隆过滤器：快速预过滤，减少 DFA 调用

---

### Q8: SSL 双向认证是怎么配置的？

**回答要点**：
- 服务端：`HttpService.start_listen()` 配置 `ssl_certfile`、`ssl_keyfile`、`ssl_ca_file`
- 客户端：`create_requests_session()` 配置客户端证书
- 验证逻辑：
  - 服务端验证客户端证书（`ssl.CERT_REQUIRED`）
  - 客户端验证服务端证书（`verify=ssl_ca_file`）
- 强制 TLS >= 1.2，禁用弱密码套件

---

### Q9: 如果密钥泄露了，怎么应急？

**回答要点**：
1. **立即更换密钥**：更新配置文件，重启服务
2. **数据重加密**：用新密钥重新加密数据库中的敏感数据
3. **审计日志**：检查访问日志，确认泄露范围和影响
4. **通知机制**：如果涉及用户数据，按法规要求通知

---

### Q10: 如果让你设计一个更强大的内容安全系统，你会怎么做？

**回答要点**：
1. **多层检测**：
   - 第一层：DFA 快速过滤（毫秒级）
   - 第二层：NLP 模型语义判断（百毫秒级）
   - 第三层：人工审核（异步）
2. **对抗样本防御**：
   - 谐音、拼音、拆字、特殊符号绕过
   - 使用更强大的分词和归一化
3. **实时更新**：
   - 敏感词库热更新，不需要重启服务
4. **用户反馈**：
   - 误拦截申诉机制，持续优化模型

## 四、手写代码题

### 题目：实现 AC 自动机（多模式 DFA）

```python
from collections import deque, defaultdict

class ACAutomaton:
    def __init__(self):
        self.trie = {}
        self.fail = {}
        self.output = defaultdict(list)
    
    def add_word(self, word):
        node = self.trie
        for char in word:
            if char not in node:
                node[char] = {}
            node = node[char]
        node['#'] = True  # 结束标记
        self.output[id(node)].append(word)
    
    def build(self):
        # BFS 构建失败指针
        queue = deque()
        # 第一层节点的失败指针指向根
        for char, node in self.trie.items():
            self.fail[id(node)] = self.trie
            queue.append(node)
        
        while queue:
            current = queue.popleft()
            for char, child in current.items():
                if char == '#':
                    continue
                # 计算失败指针
                fail_node = self.fail[id(current)]
                while char not in fail_node and fail_node is not self.trie:
                    fail_node = self.fail[id(fail_node)]
                
                if char in fail_node:
                    self.fail[id(child)] = fail_node[char]
                else:
                    self.fail[id(child)] = self.trie
                
                # 合并输出
                self.output[id(child)].extend(
                    self.output[id(self.fail[id(child)])]
                )
                queue.append(child)
    
    def search(self, text):
        results = []
        node = self.trie
        for i, char in enumerate(text):
            # 沿着失败指针跳转
            while char not in node and node is not self.trie:
                node = self.fail[id(node)]
            
            if char in node:
                node = node[char]
            
            # 检查是否有匹配
            if self.output[id(node)]:
                for word in self.output[id(node)]:
                    results.append((i - len(word) + 1, word))
        
        return results


# 使用示例
ac = ACAutomaton()
ac.add_word("暴力")
ac.add_word("暴恐")
ac.add_word("恐怖")
ac.build()

print(ac.search("打击暴恐活动"))  # [(2, '暴恐')]
```
